# Nura Cam

Free webcam effects for Windows. Trigger effects with hand gestures and use them live in Zoom, Discord, Teams or OBS.

**Status:** public beta

## Download
Get the latest installer from [Releases](../../releases/latest).

## Requirements
- Windows 10 or 11 (64-bit)
- A webcam

## Privacy
Your video is processed only on your PC. Nothing is recorded or uploaded. No account needed.

## Installing
The installer isn't code-signed yet, so Windows SmartScreen may show a warning.
Click **More info → Run anyway**. You can check the SHA-256 hash in each release's notes first.
